# DramaDist 路线图

原则：**先打通一条能用的本地闭环，再逐步加长链路**。每一版都要求可构建、可测试、界面诚实标注未接入的步骤。

---

## v0.1 — 素材 → 切片（当前）

目标：导入长视频，探测媒体信息，按规则生成切片计划并执行，产出可发布的片段。

- [x] Tauri v2 + Vue3 + Rust 工程骨架
- [x] SQLite schema（project / media / segment / task）与迁移
- [x] 外部工具定位（ffmpeg / ffprobe / python），支持手动指定路径
- [x] ffprobe 媒体探测（时长、分辨率、音轨、体积）
- [x] 切片计划：按时长均分、按集数等分、手动时间点
- [x] FFmpeg 流拷贝切片（`-c copy`，无损且快）+ 失败回退转码
- [x] 逐片进度上报（`slice:progress` 事件；尚未解析 ffmpeg `-progress` 百分比）
- [x] 单元测试覆盖切片计划边界（不足一片、超长、重叠、退化输入）
- [x] 端到端冒烟测试（真实 ffmpeg，默认跳过）

**验收**：导入一个 40 分钟视频 → 生成 40 个 1 分钟片段 → 全部文件存在且可播放。

---

## v0.2 — 字幕（ASR）

目标：为切片或整片生成字幕轴，可编辑、可导出 SRT。

- [x] `asr` 模块：探测 Python 运行时与 faster-whisper
- [x] 子进程协议：JSON 请求 / JSON 结果（避免崩溃拖死主进程）
- [x] 超时保护：超时终止子进程并报可读错误
- [x] 字幕编辑器：逐条编辑文本与时间轴、增删
- [x] 导入 / 导出 SRT（脏数据容忍 + 告警回显）
- [x] 烧进画面（导出时勾选）
- [ ] 模型目录自定义（当前用 worker 默认缓存目录）
- [ ] ASS 样式导出（字体、描边、位置）
- [ ] 批量替换 / 查找替换

---

## v0.3 — 成片导出

- [x] 烧字幕（`-vf subtitles=`）
- [x] 竖屏适配：模糊背景 / 裁切填充两种策略，输出 1080×1920
- [x] 不转画幅且不烧字幕时走流拷贝（不重编码）
- [x] 区间导出（字幕自动裁剪平移）
- [x] preset / CRF 白名单与钳制
- [ ] 片头片尾拼接（用户自己的素材）
- [ ] 导出进度上报
- [ ] 字幕烧制时的字体与样式参数

---

## v0.4 — 剪映草稿导出

- [x] 基于开源 pyJianYingDraft（Apache-2.0）生成草稿，**不自维护私有格式模板**
- [x] 切片按顺序拼成一条视频轨；字幕按切片区间裁剪后整体偏移对齐
- [x] 素材缺失 / 时长为 0 / 字幕越界一律跳过并回显告警，不静默丢内容
- [x] 草稿名做 Windows 非法字符清洗，防目录穿越与创建失败
- [x] 端到端测试：真实库生成草稿并断言内容含中文文本
- [ ] 每个切片一份独立草稿（当前是一份草稿含全部切片）
- [ ] 转场 / 滤镜 / 封面 / 音量等进阶参数
- [ ] 剪映版本兼容性说明（草稿格式随版本变化，不做全版本承诺）

## v0.6 — 画面处理（差异化）

- [x] 通用画面处理：镜像、四边裁切、缩放、亮度/对比度/饱和度、噪点、变速
- [x] 音频同步变速与音量，保证音画不脱节
- [x] 三档强度（轻微/中等/明显），参数按片段序号**确定性**生成，同批可复现
- [x] 所有数值先夹到安全范围（含 NaN / 无穷），用户输入不进命令行
- [x] 处理产物与原件同目录，`original_path` 记录原始文件，支持一键还原
- [x] 已知源尺寸时用精确像素缩放，避免反复处理导致画面逐次缩水
- [ ] 抽帧、画中画、边框、贴纸等更强处理
- [ ] 处理记录导出（哪一批用了哪组参数）
- [ ] 批量任务队列与断点续跑

## v0.5 — 发布

> 这条链路**故意只做一半**：把「准备」做到位，把「发送」交回给人。
> 理由是视频号没有公开 API、开放平台需要企业资质、网页自动化有封号与协议风险。
> 详见 README「为什么没有一键自动发布」。

- [x] 平台清单（抖音 / 视频号 / B站 / 快手），**如实标注各平台是否有公开发布 API**
- [x] 发布设置：标题、简介、标签、封面、备注，按「素材 × 平台」唯一存储
- [x] 发布包导出：`clips/` + `subtitles/` + `cover.jpg` + `metadata.json` + `README.txt`
- [x] 封面：可指定图片，未指定时自动从视频抽帧（失败只告警不中断）
- [x] 标题自动按片段编号：`标题（2/12）`
- [x] 本地发布台账：草稿 / 待发布 / 已发布 / 失败 + 备注，支持按状态回溯
- [x] README.txt 明确声明「本次导出只在本地整理文件，没有向任何平台发送任何内容」
- [ ] 官方接口接入（等用户拿到资质后实现，接口位置已预留）
- [ ] 发布包批量导出（一个项目下所有素材一次导出）
- [ ] 台账导出 CSV

## v0.7 — 补齐（进行中）

对标原软件的其余能力，全部独立实现、行为等价：

- [x] **去重效果验证**：ffmpeg 抽帧 → dHash 感知哈希 → 汉明距离 → 相似度与结论；
      按相对位置抽帧，处理前后时长不同也能逐帧对齐；结论明确声明「只说明改动幅度，不承诺过任何平台判重」
- [ ] **OCR 硬字幕识别**：RapidOCR（Apache-2.0）识别画面里的硬字幕 → 生成字幕轴
- [ ] **集数重切与剧目重组**：按集重切、按命名规则把素材归到剧目
- [ ] **批量任务队列与断点续跑**：长任务统一排队，可中断可续跑
- [ ] **多账号发布台账**：同一素材支持多个账号维度记账
- [ ] **云端字幕适配器**：用户自备 Key（火山引擎），与本地 whisper 二选一
- [ ] **证明材料生成**：按模板生成 docx 证明材料
- [ ] **用户自备素材库**：音效/滤镜由用户导入自己的素材（不内置任何第三方资产）

### 明确不做

- 自动发布（浏览器自动化 + 反检测浏览器）：封号风险 + 违反平台协议
- 照搬第三方软件的特效/音效/模板资产
- 任何形式的授权绕过或破解

---

## 长期不做

- 不复制任何第三方软件的代码、素材、文案、数据表
- 不做账号绕过、授权破解、协议逆向
- 不内置来源不明的 FFmpeg 或模型二进制
