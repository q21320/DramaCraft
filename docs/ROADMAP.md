# DramaDist 路线图

原则：**先打通一条能用的本地闭环，再逐步加长链路**。每一版都要求可构建、可测试、界面诚实标注未接入的步骤。

---

## v0.1 — 素材 → 切片（当前）

目标：导入长视频，探测媒体信息，按规则生成切片计划并执行，产出可发布的片段。

- [x] Tauri v2 + Vue3 + Rust 工程骨架
- [x] SQLite schema（project / media / segment / task）与迁移
- [x] 外部工具定位（ffmpeg / ffprobe / python），支持手动指定路径
- [x] ffprobe 媒体探测（时长、分辨率、音轨、体积）
- [x] 切片计划：按时长均分、按集数等分、手动时间点
- [x] FFmpeg 流拷贝切片（`-c copy`，无损且快）+ 失败回退转码
- [x] 逐片进度上报（`slice:progress` 事件；尚未解析 ffmpeg `-progress` 百分比）
- [x] 单元测试覆盖切片计划边界（不足一片、超长、重叠、退化输入）
- [x] 端到端冒烟测试（真实 ffmpeg，默认跳过）

**验收**：导入一个 40 分钟视频 → 生成 40 个 1 分钟片段 → 全部文件存在且可播放。

---

## v0.2 — 字幕（ASR）

目标：为切片或整片生成字幕轴，可编辑、可导出 SRT。

- [x] `asr` 模块：探测 Python 运行时与 faster-whisper
- [x] 子进程协议：JSON 请求 / JSON 结果（避免崩溃拖死主进程）
- [x] 超时保护：超时终止子进程并报可读错误
- [x] 字幕编辑器：逐条编辑文本与时间轴、增删
- [x] 导入 / 导出 SRT（脏数据容忍 + 告警回显）
- [x] 烧进画面（导出时勾选）
- [ ] 模型目录自定义（当前用 worker 默认缓存目录）
- [ ] ASS 样式导出（字体、描边、位置）
- [ ] 批量替换 / 查找替换

---

## v0.3 — 成片导出

- [x] 烧字幕（`-vf subtitles=`）
- [x] 竖屏适配：模糊背景 / 裁切填充两种策略，输出 1080×1920
- [x] 不转画幅且不烧字幕时走流拷贝（不重编码）
- [x] 区间导出（字幕自动裁剪平移）
- [x] preset / CRF 白名单与钳制
- [ ] 片头片尾拼接（用户自己的素材）
- [ ] 导出进度上报
- [ ] 字幕烧制时的字体与样式参数

---

## v0.4 — 剪映草稿导出

- [x] 基于开源 pyJianYingDraft（Apache-2.0）生成草稿，**不自维护私有格式模板**
- [x] 切片按顺序拼成一条视频轨；字幕按切片区间裁剪后整体偏移对齐
- [x] 素材缺失 / 时长为 0 / 字幕越界一律跳过并回显告警，不静默丢内容
- [x] 草稿名做 Windows 非法字符清洗，防目录穿越与创建失败
- [x] 端到端测试：真实库生成草稿并断言内容含中文文本
- [ ] 每个切片一份独立草稿（当前是一份草稿含全部切片）
- [ ] 转场 / 滤镜 / 封面 / 音量等进阶参数
- [ ] 剪映版本兼容性说明（草稿格式随版本变化，不做全版本承诺）
