# DramaDist 路线图

原则：**先打通一条能用的本地闭环，再逐步加长链路**。每一版都要求可构建、可测试、界面诚实标注未接入的步骤。

---

## v0.1 — 素材 → 切片（当前）

目标：导入长视频，探测媒体信息，按规则生成切片计划并执行，产出可发布的片段。

- [x] Tauri v2 + Vue3 + Rust 工程骨架
- [x] SQLite schema（project / media / segment / task）与迁移
- [x] 外部工具定位（ffmpeg / ffprobe / python），支持手动指定路径
- [x] ffprobe 媒体探测（时长、分辨率、音轨、体积）
- [x] 切片计划：按时长均分、按集数等分、手动时间点
- [x] FFmpeg 流拷贝切片（`-c copy`，无损且快）+ 失败回退转码
- [ ] 切片进度实时上报（解析 `-progress`）
- [ ] 单元测试覆盖切片计划边界（不足一片、超长、重叠）

**验收**：导入一个 40 分钟视频 → 生成 40 个 1 分钟片段 → 全部文件存在且可播放。

---

## v0.2 — 字幕（ASR）

目标：为切片或整片生成字幕轴，可编辑、可导出 SRT。

- [ ] `asr` 模块：探测 Python 运行时与 faster-whisper
- [ ] 子进程协议：JSON 请求 / JSON 结果（避免崩溃拖死主进程）
- [ ] 模型管理：首次使用提示下载，落到用户数据目录
- [ ] 字幕编辑器：时间轴对齐、逐条编辑、批量替换
- [ ] 导出 SRT / ASS，并可选择"烧进画面"

**验收**：一段 10 分钟中文视频，字幕后准确率可用，SRT 能被播放器正确加载。

---

## v0.3 — 成片导出

- [ ] 烧字幕（`-vf subtitles=`）与可选硬编码
- [ ] 竖屏适配：横屏转 9:16（模糊背景 / 裁切两种策略）
- [ ] 片头片尾拼接（用户自己的素材）
- [ ] 导出预设与进度上报

---

## v0.4 — 剪映草稿导出

- [ ] 研究草稿 JSON 结构，生成可被剪映打开的草稿
- [ ] 素材路径映射与缺失检测
- [ ] 仅在剪映版本兼容范围内声明支持，不承诺全版本

---

## v0.6 — 去重与批量

- [ ] 画面处理（裁剪/缩放/镜像/抽帧）与音频变调

- [ ] 批量任务与断点续跑

---

## 明确不做

- 不复制任何第三方软件的代码、素材、文案、数据表
- 不做账号绕过、授权破解、协议逆向
- 不内置来源不明的 FFmpeg 或模型二进制
